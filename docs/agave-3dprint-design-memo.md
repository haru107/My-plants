# 平面アガベ 3Dプリント作品 — 再現用 設計メモ

黒PLAで作った「平面（2D）アガベのライン作品＋茎＋根」を作り直すためのメモ。
花瓶に挿したり、鉢に挿してフェイクグリーン／オブジェとして飾るやつ。

> 写真の特徴：輪郭線を重ねた“スケッチ／ワイヤー風”の平面ロゼット（多肉の葉が放射状）＋
> 下に長く垂れた1本の茎＋先端で数本に枝分かれした根と小さな球（球根風）。

---

## 0. 全体パイプライン（線画 → 3Dプリントまで）

```
①素材写真   ②線画(2D)     ③整える      ④3D化(押し出し)   ⑤スライス     ⑥印刷
 .jpg    →  .svg(線)  →  .svg(連結)  →   .stl/.3mf    →  .gcode   →  実物
 (写真)     (Inkscape等)  (印刷用に)     (Tinkercad等)    (スライサー)   (プリンタ)
```

**最重要ポイント：「平面の線画に“厚み”を与えて押し出す（④）と3Dデータになる」**

| 工程 | やること | ツール | 入力→出力 |
|------|---------|--------|-----------|
| ① 素材 | 無地背景・真上から撮った写真1枚（品質の8割） | カメラ | — → `.jpg` |
| ② 線画化 | 写真をトレースして輪郭線にする（**リアルさ担当**） | potrace/OpenCV/Inkscape | `.jpg` → `.svg`(厚みゼロ) |
| ③ 整える | 線を`Stroke to Path`で帯化／全部1本に連結／細線を太く | Inkscape | `.svg` → `.svg`(印刷用) |
| ④ **3D化** | **平面に厚み2mmを与えて立体に（=2D→3Dの正体）** | Tinkercad/Fusion/Blender | `.svg` → `.stl`/`.3mf` |
| ⑤ スライス | 寝かせ配置・ブリム・サポート無でG-code化 | Bambu/Orca/Prusa/Cura | `.stl` → `.gcode` |
| ⑥ 印刷 | 黒PLAで平らに印刷→ブリム除去→茎/根仕上げ→花瓶/鉢に挿す | 3Dプリンタ | `.gcode` → 実物 |

> ④の「押し出し（Extrude）」がカギ：クッキー型を平らに寝かせたような“厚み2mmの板”になる。
> Tinkercadなら **Import → SVG読込 → Height=2mm** にするだけで3D化できる。
> ②でリアルな線を作れれば、あとは④に放り込むだけ。

## 1. 作品の特徴分析（再現で外さないポイント）

| 要素 | 観察 | 再現のキモ |
|------|------|-----------|
| 全体スタイル | 面で塗らず、**輪郭線だけ**を重ねた線画 | 「塗り」ではなく「線」で作る＝線幅＝印刷の線幅 |
| ロゼット | 先のとがった葉が3〜4層、放射状に重なる | 外周ほど大きく寝かせ、中心は立てて重ねる |
| 葉の中の線 | 葉の中に乱れたクロス線（葉脈／陰影風） | わざと交差線を入れるとあの“密度感”が出る |
| 茎 | 1本の細い線がS字に垂れる | 1本のパスを長く。少し曲げると自然 |
| 根 | 先端で3〜4本に枝分かれ＋小さな球 | 細い線を分岐。球は小さな塊にして“重し兼アクセント” |
| 色 | 黒（マット） | 黒PLA or PETG。マット系フィラメントが雰囲気◎ |
| 厚み | 数mmの平板（壁から飾れる薄さ） | 1.5〜3mm程度 |

ポイントは「**面ではなく線で構成された平面オブジェ**」であること。
モデリングの考え方が普通の立体とは違う（下記）。

---

## 2. 必要なもの

- **3Dプリンタ**（FDM。ノズル0.4mmでOK）
- **黒フィラメント**：PLA（手軽）／PETG（屋外・しなり強め）／マットPLA（質感◎）
- **モデリング or 変換ツール**（下のどれか1つ）
  - お手軽：**Tinkercad**（SVG読み込み→押し出し）
  - 中級：**Fusion 360**（SVG挿入→スケッチ→押し出し）
  - ベクター作成：**Inkscape**（写真／下絵を線画SVGに）
  - スライサー：Bambu Studio / OrcaSlicer / PrusaSlicer / Cura

---

## 3. 設計手順（おすすめ＝SVGライン作戦）

「線で作る」ので、**SVGの線（ストローク）→押し出し**が一番ラク＆あの雰囲気が出る。

### STEP 1. 下絵を用意
- アガベ／多肉のロゼットを**真上から見た線画**を用意する。
  - 自分でラフを描く → 写真に撮る → Inkscapeでトレース、でもOK
  - 既存のアガベ写真（このリポジトリの `img/AGV***` が参考になる）を見ながら葉の枚数・角度を決める

### STEP 2. Inkscape で線画SVG化
1. 下絵を読み込む
2. ベジェ／鉛筆ツールで葉を1枚ずつ輪郭取り（外側の大きい葉→内側へ）
3. 葉の中に**わざとクロス線を数本**入れる（あの密度感の正体）
4. 茎を**1本の長い曲線**で下へ。先端で**3〜4本に分岐**させて根に
5. 根の先に**小さな円**を1つ（球根風／重し）
6. すべての線を **Stroke（線）** にし、線幅を **1.2〜2.0mm**（＝印刷の太さ）に
7. 線を「**Stroke to Path（線をパスに変換）**」して面のあるパスにする
   - ※これをやらないと押し出しで消えるツールがある
8. `Path > Union` で重なりを結合（任意）
9. SVGで保存

### STEP 3. 押し出して平板化
- **Tinkercad** の場合：Import → SVG → 高さ（Height）を **1.5〜3mm** に設定
- **Fusion 360** の場合：Insert > SVG → スケッチ化 → Extrude **1.5〜3mm**
- これで「線でできた平面プレート」になる

### STEP 4. つながりチェック（重要）
- **全部のパーツが1つに繋がっているか**確認（葉同士・茎・根）。
  - 浮いた線があるとその部分だけ別ピースで印刷されて落ちる
  - 葉のクロス線は必ずどこかで輪郭に接触させる
- 茎は折れやすいので、**根元（ロゼットと茎の接続部）を少し太め**に。

### STEP 5. 書き出し → STL/3MF

## 4. 茎・根の作り方（折れ・自立対策）

- **茎の太さ**：細すぎると折れる。最低でも線幅 **1.5mm以上**、長いなら2mm。
- **茎の曲げ**：まっすぐより緩いS字の方が自然で、挿したとき表情が出る。
- **根の分岐**：3〜4本。長さをバラけさせるとリアル。
- **先端の球**：花瓶／鉢に挿したとき**重し**になり、ぐらつき防止＆デザインアクセント。
  - 球を少し厚め（4〜5mm）にすると重心が下がって安定する。

---

## 5. スライス設定の目安（線画平板向け）

| 項目 | 値 | 理由 |
|------|----|------|
| レイヤー高 | 0.2mm | 標準でOK |
| 壁（Walls/Perimeters） | **多め（4〜6）** or 線幅≒壁で埋まる設計に | 線が細いので壁だけで中身が埋まる＝強度UP |
| インフィル | 線が細ければ実質不要／15% | 太い部分の充填用 |
| 底面レイヤー | 3〜4 | 平面なので底面の質が見た目に直結 |
| **ブリム** | 5〜8mm 推奨 | 接地面が線だけで細く剥がれやすい→反り防止 |
| サポート | **不要**（完全に平面なら） | ベタ置きで寝かせて印刷 |
| 速度 | 細線は気持ちゆっくり | 細い線の造形精度UP |

> 平らに寝かせて印刷するのが基本。接地が「線」だけで剥がれやすいので**ブリムは必須級**。

---

## 6. 印刷のコツ／トラブル対策

- **剥がれる／反る** → ブリム＋ベッド清掃＋1層目をゆっくり＆少し潰し気味に。
- **細線が途切れる** → 線幅を太く（最低 ノズル径×3 = 1.2mm〜）。
- **茎が折れた** → 茎を太く or PETGに変更（しなる）。
- **ペラペラで頼りない** → 厚みを2.5〜3mmへ。または葉を少し前後にずらして立体感を出す（中心の葉だけ別レイヤーで重ねる）。
- **マット感が欲しい** → マットPLA、または印刷後につや消しスプレー。

---

## 7. 飾り方バリエーション

- **花瓶挿し**：細口の一輪挿しに、根＋球ごと入れる（球が重しに）。
- **鉢挿し**：鉢に土／砂利、茎を挿して本物の多肉に混ぜる。
- **壁掛け**：茎をループにして引っ掛け穴に。
- **複数本**：葉数・サイズ違いで数本作って群生風に。

---

## 8. 次に作るときの改善アイデア（メモ）

- [ ] 葉を2〜3パーツに分け、中心だけ1層持ち上げて**半立体**化
- [ ] 茎の接続部にフィレット（R）を付けて折れ防止
- [ ] 球（根元）を中空＋穴にして本物の花瓶水に挿しても割れないように
- [ ] サイズ違い（S/M/L）のSVGテンプレを残しておく
- [ ] 完成品をこのコレクションサイトに「自作オブジェ」として記録（要：カテゴリ追加）
